## What are we solving?

Given an unsorted array of integers, find the length of the **longest consecutive elements sequence**. For example, in `[100, 4, 200, 1, 3, 2]`, the consecutive sequence `[1, 2, 3, 4]` has length 4. The catch: you must do this in $O(n)$ time — so sorting is off the table (well, $O(n \log n)$ technically). **How do you find sequences without sorting?**

**Example 1:**
```
Input:  nums = [100,4,200,1,3,2]
Output: 4
Explanation: Longest consecutive sequence is [1, 2, 3, 4].
```

**Example 2:**
```
Input:  nums = [0,3,7,2,5,8,4,6,0,1]
Output: 9
```

**Constraints:**
- $0 \le$ nums.length $\le 10^5$
- $-10^9 \le$ nums[i] $\le 10^9$

## Approach 1 — Sorting

**First idea:** Sort the array, then scan for consecutive elements. Simple but $O(n \log n)$.

```
nums = [100, 4, 200, 1, 3, 2]
sorted: [1, 2, 3, 4, 100, 200]

streak=1: 1→2 consecutive, streak=2
         2→3 consecutive, streak=3
         3→4 consecutive, streak=4
         4→100 break, reset streak=1
         100→200 break, reset streak=1
max = 4 ✓
```

Correct, but $O(n \log n)$ from sorting. The problem asks for $O(n)$.

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        if (nums.empty()) return 0;
        sort(nums.begin(), nums.end());
        int maxLen = 1, streak = 1;
        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] == nums[i-1]) continue;  // skip duplicates
            if (nums[i] == nums[i-1] + 1) streak++;
            else streak = 1;
            maxLen = max(maxLen, streak);
        }
        return maxLen;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \log n)$ | $O(1)$ |

> Works but doesn't meet the $O(n)$ requirement.

## Approach 2 — Hash Set with Sequence Start Detection ✅

**The trick:** Put all numbers in a hash set. Then for each number, check if `num - 1` exists — if it does, this number isn't the **start** of a sequence, so skip it. If `num - 1` doesn't exist, this IS a sequence start — count forward (`num+1, num+2, ...`) as long as they exist in the set.

```
nums = [100, 4, 200, 1, 3, 2]
set = {100, 4, 200, 1, 3, 2}

num=100: 99 not in set → start! count: 100 → length 1
num=4:   3 in set → skip (not a start)
num=200: 199 not in set → start! count: 200 → length 1
num=1:   0 not in set → start! count: 1,2,3,4 → length 4
num=3:   2 in set → skip
num=2:   1 in set → skip

max = 4 ✓
```

Each element is visited at most twice (once in the outer loop, once when counting forward). Total: $O(n)$.

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> numSet(nums.begin(), nums.end());
        int maxLen = 0;
        
        for (int num : numSet) {
            if (!numSet.count(num - 1)) {       // start of a sequence
                int current = num;
                int streak = 1;
                while (numSet.count(current + 1)) {
                    current++;
                    streak++;
                }
                maxLen = max(maxLen, streak);
            }
        }
        return maxLen;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(n)$ |

> **This is the one.** True $O(n)$ — the "skip non-starts" trick ensures no redundant work.

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Empty array | No elements → length 0 | Returns 0 immediately |
| Duplicates | `[1,2,0,1]` — ignore duplicates | Set handles this automatically |
| Single element | `[5]` → length 1 | It's a start, no extensions |
| All consecutive | `[1,2,3,4,5]` → length 5 | Only one sequence start (1), counts all |

---

## Pattern Takeaway

The **"sequence start detection"** trick is elegant: skip elements that aren't the beginning of anything. This ensures linear time despite a nested loop. The pattern of "only process items that are the start of something" appears in many problems — interval merging, chain-finding, etc.
