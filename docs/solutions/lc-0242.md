## What are we solving?

Given two strings `s` and `t`, determine if `t` is an **anagram** of `s` — meaning `t` is just a rearrangement of the characters in `s`. Both strings must use exactly the same characters with the same frequencies. The question is: **what's the most efficient way to compare character frequencies?**

**Example 1:**
```
Input:  s = "anagram", t = "nagaram"
Output: true
```

**Example 2:**
```
Input:  s = "rat", t = "car"
Output: false
```

**Constraints:**
- $1 \le$ s.length, t.length $\le 5 \times 10^4$
- `s` and `t` consist of lowercase English letters

## Approach 1 — Sorting

**First instinct:** If two strings are anagrams, sorting them both should give the same result. "anagram" → "aaagmnr", "nagaram" → "aaagmnr" — match!

```
s = "anagram", t = "nagaram"
sorted(s) = "aaagmnr"
sorted(t) = "aaagmnr"
Equal → return true ✓
```

Simple, but sorting is $O(n \log n)$. Can we do better?

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;
        sort(s.begin(), s.end());
        sort(t.begin(), t.end());
        return s == t;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n \log n)$ | $O(1)$ |

> Works well but not optimal. Let's try counting.

## Approach 2 — Frequency Count (Array) ✅

**Better idea:** Since we only have 26 lowercase letters, use an array of size 26. Increment for each char in `s`, decrement for each char in `t`. If all counts end at zero — it's an anagram.

```
s = "anagram", t = "nagaram"
count[26] initialized to 0

Process s: a→2, n→1, g→1, r→1, m→1
Process t: n→0, a→1, g→0, a→0, r→0, a→-1... wait

Actually, let's track properly:
After s:  a:3 g:1 m:1 n:1 r:1
After t:  a:0 g:0 m:0 n:0 r:0
All zero → true ✓
```

One pass through each string, constant-size array. Optimal!

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;
        int count[26] = {};
        for (char c : s) count[c - 'a']++;
        for (char c : t) count[c - 'a']--;
        for (int i = 0; i < 26; i++)
            if (count[i] != 0) return false;
        return true;
    }
};
```

| Time | Space |
|:-----|:------|
| $O(n)$ | $O(1)$ |

> **This is the one.** Linear time, constant space (fixed 26-size array).

## Edge Cases to Watch

| Case | Trap | How it's handled |
|:-----|:-----|:-----------------|
| Different lengths | Can't be anagrams | Early return `false` |
| Empty strings | Both empty → anagram of each other | All counts zero → `true` |
| Single char | `"a"` vs `"a"` → true, `"a"` vs `"b"` → false | Works naturally |
| Unicode/uppercase | Follow-up: use a hash map instead of array | Problem says lowercase only |

---

## Pattern Takeaway

**Frequency counting** is the go-to technique for anagram/permutation problems. Fixed-size array for known character sets (26 letters), hash map for arbitrary characters. You'll see this exact pattern in "Group Anagrams," "Permutation in String," and "Find All Anagrams."
